# Engineering Journal

## Purpose

This journal records engineering incidents, debugging sessions, production-like issues, architectural decisions, and lessons learned while building FocusGuard.

Unlike sprint notes, these entries are not tied to a particular feature. They document real engineering experiences that improve debugging, troubleshooting, and system understanding.

Each entry contains:

- Incident Summary
- Symptoms
- Investigation
- Root Cause
- Recovery
- Lessons Learned
- Commands Used
- Future Improvements
- Interview Talking Points

The goal is to build an engineering knowledge base alongside the project.
